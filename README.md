Project 1: 緯創軟體員工流動分析專案
專案介紹：
該專案旨在協助企業了解員工流動的原因，並通過數據分析提供具體的改善建議，以提升員工滿意度和留任率。

主要工作：
數據清理與預處理：對來自各部門的員工數據進行清洗，解決缺失數據、異常值和不一致性問題。
員工流動趨勢分析：分析員工的流動趨勢，探索不同部門、年資、職位等因素對員工流動率的影響。
數據儀表板設計：建立動態儀表板，使管理層能隨時查看關鍵員工指標和流動情況。
主要挑戰：
分析員工流動的複雜性：員工流動受到多種因素影響，需在大量變數中找到最具代表性的因素，且需要消除干擾因素的影響。
決策所需的深度分析：分析不僅僅是揭示流動數據，還需要提出行動建議，並為未來的員工保留計劃提供具體指導。
結果：
該專案幫助企業深入理解員工流動的核心因素，並提供了量化的行動建議，有效改進了企業的員工保留策略，提高了員工滿意度和整體業務績效。

Project 2: 蝦皮數據分析專案
專案介紹：
此專案的目標是透過數據分析來洞察蝦皮平台的市場需求及行銷效益，並為後續的商業策略提供支持。主要的分析工作包括數據清理、行銷效益分析以及視覺化呈現。

主要工作：
數據清理與處理：針對不完整或異常的數據進行清理，保證數據的準確性與一致性。
行銷效益分析：分析促銷活動及其他行銷手段的成效，並找出關鍵驅動因素。
視覺化報告：創建動態報告，協助業務團隊快速理解分析結果。
主要挑戰：
行銷效果度量難度：需要從大量的行銷數據中分辨出哪些活動對銷售增長最具影響力，並避免過度簡化。
業務需求多變性：隨著專案進行，業務需求的變動要求分析結果能迅速調整和更新。
結果：
通過深入的數據分析，我們成功識別了關鍵的行銷活動模式，並向業務團隊提供了優化建議，提升了行銷策略的針對性及效益，最終促進了銷售增長。
